# DataWorth KZ

**An Intelligent Framework for Financial Data Valuation and Privacy-Aware Credit Risk Optimization in Kazakhstan’s Open Banking Ecosystem**

Ғылыми прототип: қаржылық ақпарат топтарының банкке әкелетін экономикалық құнын Data Value Frontier (DVF) моделі арқылы бағалайды.

> **Маңызды:** эксперимент UCI «Default of Credit Card Clients» деректерімен жүргізілді (Тайвань, 2005, n = 30 000). Бұл Қазақстан немесе Open Banking деректері емес. Ақшалай параметрлер (маржа, LGD, CCF, деректер құны, λ) — болжам. Прототип ешбір нақты банк жүйесіне қосылмаған.

## 6. Әдістеме қысқаша
- Бөлу: stratified 70/15/15, seed = 42. Preprocessing — тек train; гиперпараметрлер, шешім шегі және оңтайлы жиынтық — тек validation; test — бір рет, соңғы бағалау.
- Демографиялық белгілер (SEX, EDUCATION, MARRIAGE, AGE) әдейі қолданылмайды.
- EAD = max(BILL_AMT1, 0) + CCF · max(LIMIT_BAL − BILL_AMT1, 0)
- Π(S) = Σ_{PD<t} [(1 − y)·m·EAD − y·LGD·EAD];  V(S) = Π(S) − Π(S₀) − C(S)
- C(S) = N · [c · |топтар| + λ · |өрістер − 2|] · EAD̄ · 10⁻⁴

## 7. Болашақ интеграция (тек ұсыныс)
Open API арқылы клиенттің келісімімен (ҰТК/ҰБ платформасы) ақпарат топтарын түйіршікті сұрау → DataWorth сервисі DVF бойынша ең аз жеткілікті жиынтықты ұсынады → банк скоринг моделі. Бұл архитектуралық ұсыныс; іске асырылмаған және тексерілмеген.

## 8. Аудиттен кейінгі түзетулер (қараша 2026)
- H1 non-inferiority тәсілімен қайта тексерілді (results/revision_bootstrap.csv): GB — расталды (U95 = −44 NT$), RF — расталмады (U95 = 692 NT$).
- EAD тек лимит арқылы есептелген нұсқа (EAD = 0,5·LIMIT_BAL) қосылды — базалық қорытынды өзгермейді.
- λ* = 8,64 б.п./өріс, c* ≈ 13 б.п./топ — оңтайлы жиынтық 6 → 3 өріске ауысатын шектер.
- Уақыт көкжиегіне сәйкес айлық сценарий (m = 2%, LGD = 75%): нәтиже орнықсыз.
- Ескерту: бұл нұсқалар тек зерттеу скриптінде, Streamlit қосымшасында жоқ.

## 9. Қазақстанға бейімдеу: аралас зерттеу тәсілі (қараша 2026)
- **Тайвань деректері (UCI, 2005)** — тек PD модельдері, алгоритмдерді және 64 ақпарат жиынтығын салыстыру.
- **Қазақстан статистикасы** — тек қаржылық параметрлер: тұтынушылық қарыз мөлшерлемесі 22,5% және жеке тұлғалар депозиті 14,7% (ҚНРДА, шілде 2026), базалық мөлшерлеме 15,75% (ҰБ, 23.10.2026), бір кредитке шаққандағы орташа қарыз ≈ 698 мың ₸ (кредиттік бюро, 01.01.2026).
- NPL90+ клиенттің PD-і ретінде қолданылмайды; екі елдің деректері бір кестеге біріктірілмейді.
- Сценарийлер: 1 — базалық (m = 7,8%, LGD 75%), 2 — жоғары тәуекел (6,75%, 90%), 3 — деректер құны жоғары (c = 10 б.п., λ = 5 б.п.), айлық көкжиек тексерісі (0,65%).
- Қайталау: `python kz_adaptation.py && python kz_extra.py && python make_kz_figure.py && python make_kz_market.py && python add_kz_sheets.py` → results/kz_*.csv, figures/kz_scenarios.png, Excel-дегі KZ_* парақтары.
- Қосымшада жаңа «Қазақстан сценарийлері» бөлімі (теңге, өз параметрлерін енгізу, үш сценарийді салыстыру).
- H4 ішінара расталды: оңтайлы жиынтық 1 және 2 сценарийде 6 өріс күйінде қалды, бірақ жоғары тәуекелде B-ның C-дан кем еместігі расталмады (U95 = 98% Π(B)), деректер құны жоғары болғанда validation 3 өрісті таңдады (тұрақсыз).
- Барлық теңгедегі сандар — сценарийлік есеп, Қазақстан банктерінің нақты пайдасы емес.
